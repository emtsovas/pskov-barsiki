# Хранители Пскова

Сайт для бизнес-проекта городского бренда «Хранители Пскова», вдохновлённого историей Пскова, образом барса и псковскими Барсиками.

На сайте представлена концепция бренда и коллекции одежды, информация о Барсиках, городской маршрут, квест и фотогалерея.

## Функциональность

- адаптивный лендинг;
- интерактивные карточки Барсиков;
- фильтрация и просмотр информации о героях;
- переход к точкам на карте;
- слайдер коллекции одежды;
- городской маршрут и информация о квесте;
- фотогалерея.
